# ocean-dm-hw

《海洋数据挖掘技术》课程大作业 —— 切入点：**AI 智能体的存档粒度与幂等键粒度**

> 题目：扇出效应的"部分完成"盲区：AI 智能体存档粒度与幂等键粒度的一致性实验
> 场景：台风预警群发智能体（第 3 讲综合案例）

## 一句话结论

第 3 讲说"可持久化执行 = 存档点 + 唯一编号"。本文证明：当一次工具调用**扇出**成 N 个子效应时，步级存档相对轮级存档只减少 6.2% 的重复（N=50, p=30%），工业界的两相调用日志**毫无改善**却贵 30 倍；提出"扇出效应账本"把重复压到 −97.7%，并给出采用门槛的解析式 $\alpha/\beta > 4(N+6)/(pN)$。

- 章标题 黑体三号居中，节标题 黑体四号
- 图题置于图下（五号宋体居中），表题置于表上（五号黑体居中）
- 页脚居中页码：封面不编码，摘要与目录用小写罗马数字，正文从 1 起
- 参考文献按 GB/T 7714—2015 著录

## 自检

```bash
python tools/check.py
```

会核对：表 3 每个数字与 `results/main_summary.csv` 是否一致、正文百分比能否由数据复算、
参考文献引用是否闭合、图/表是否齐全且在正文被引用、docx 里有无 Markdown 残留与 ASCII 引号、
报告链接与 git remote 是否一致、对话记录是否含导航且已脱敏。退出码非 0 即有问题。

## 复现

```bash
python sim/run_main.py    # 约 10 秒
python sim/analyze.py     # 约 1 分钟
```

依赖：Python 3.10+、matplotlib。无需 API key、无需 GPU。
随机种子由 `(策略, N, p)` 哈希固定，结果可逐位复现。
